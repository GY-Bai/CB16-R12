# Current Canonical Authority

Authority class: **CURRENT_CANONICAL**.

Files in this directory are the first documentation context for present scientific interpretation, review, and promotion decisions.

## Current authority

- `AUTHORITY_INDEX.json` — machine-readable authority classes, default-context policy, and reading order.
- `R12_EVIDENCE_SCOPE_AND_CLAIM_AUTHORITY.md` — claim scope, experiment roles, verification vs validation, estimand/inference boundaries, PASS/FAIL interpretation, dependency types, promotion authority, adaptive data exposure, and temporal governance.
- `TASK_REVIEW_PROTOCOL.md` — task construction, two-stage scientific protocol/result review, immutable execution, diagnostic/screening rules, complexity admission, and evidence handling.

## Precedence

Canonical authority does not rewrite frozen historical gates or observations. It governs how present work may interpret, transfer, compose, or promote evidence from them.

A specific frozen experiment contract remains authoritative for that experiment's original method, budget, controls, and gate. It does not override newer canonical rules about the scope of conclusions or current promotion.

No draft, experiment contract, archive file, operator note, or template belongs in this directory.
