# Current Design Candidates

Authority class: **CURRENT_DESIGN_CANDIDATE**.

`current/` contains active R12 design contracts/candidates that may guide implementation or experiments but are **not equal to canonical project-wide scientific authority**.

They are subordinate to `../authority/` and may be revised when new evidence or owner decisions change the candidate design.

Current files include the core objective/qualification draft, action-permission-account physics candidate, and minimal learner candidate.

A PASS involving one of these candidates qualifies only the tested claim/scope. It does not freeze the candidate as the final CB16 architecture.
